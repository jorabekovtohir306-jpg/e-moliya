# Э-МОЛИЯ — телефонга илова қилиб ўрнатиш

Шу папкадаги учта файл тайёр сайт. Уни GitHub Pages га жойласангиз, телефонда
**ҳақиқий илова** бўлиб ўрнатилади: ўз иконкаси билан, браузер панелисиз, интернетсиз ишлайди.

| Файл | Вазифаси |
|---|---|
| `index.html` | Дастурнинг ўзи (барча код шу файлда) |
| `manifest.json` | Илова номи, иконкаси, ранги |
| `sw.js` | Офлайн ишлаши (service worker) |

---

## 1-йўл: браузер орқали (энг осони, 5 дақиқа)

1. **github.com** га киринг, бепул аккаунт очинг (агар йўқ бўлса).
2. Ўнг юқоридаги **+** → **New repository**.
   - Repository name: `e-moliya`
   - **Public** ни танланг
   - **Create repository** ни босинг.
3. Очилган саҳифада **uploading an existing file** ҳаволасини босинг.
4. Шу папкадаги **учта файлни** (`index.html`, `manifest.json`, `sw.js`) ойнага судраб ташланг →
   пастдаги **Commit changes** ни босинг.
5. **Settings** → чап устундаги **Pages** бўлими:
   - Source: **Deploy from a branch**
   - Branch: **main** ва **/ (root)** → **Save**
6. 1–2 дақиқа кутинг. Ўша саҳифада манзил чиқади:
   **`https://ФОЙДАЛАНУВЧИ-НОМИ.github.io/e-moliya/`**

## 2-йўл: git орқали (компьютердан)

GitHub да бўш `e-moliya` репозиторийси очилгач, шу папкада:

```bash
git remote add origin https://github.com/ФОЙДАЛАНУВЧИ-НОМИ/e-moliya.git
git branch -M main
git push -u origin main
```

Кейин Settings → Pages дан юқоридаги 5-қадамни бажаринг.

---

## 2. Телефонга ўрнатиш

**Android (Chrome):** манзилни браузерда очинг → ўнг юқоридаги ⋮ меню →
**«Ilovani o'rnatish»** ёки **«Экранга қўшиш»**.

**iPhone (Safari):** манзилни Safari да очинг (Chrome эмас!) → пастдаги **Ulashish** (квадрат+стрелка) →
**«Bosh ekranga qo'shish»**.

Шундан сўнг иловани иконкадан очасиз — интернет керак эмас.

---

## Муҳим

- Репозиторий **оммавий** бўлади, яъни дастур **коди** кўринади. Лекин молиявий
  маълумотингиз кодда эмас — у фақат сизнинг телефонингиз хотирасида сақланади
  ва ҳеч қаерга юборилмайди.
- Маълумотни вақти-вақти билан **Созлама → JSON экспорт** орқали заҳиралаб туринг.
- Дастурни янгилаганда `index.html` ни алмаштириб, `sw.js` ичидаги `emoliya-v2`
  ёзувини `emoliya-v3` га ўзгартиринг — шунда телефондаги эски нусха янгиланади.
